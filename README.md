## Engineering Approach

I use AI-assisted development as an engineering methodology,
not as a substitute for technical verification.

My workflow emphasizes:

- **Specification:** Define requirements, interfaces,
  constraints, and acceptance criteria.
- **Architecture:** Separate responsibilities and establish
  clear component boundaries.
- **Implementation:** Use coding agents for scoped
  development tasks.
- **Verification:** Evaluate changes through automated tests,
  CI, and targeted reviews.
- **Integration:** Preserve traceability between requirements,
  implementation, and verified results.

Architecture decisions, technical acceptance, and final
integration remain human responsibilities.
